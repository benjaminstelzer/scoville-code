# Python interpreter

For Python commands and bundled helpers, reuse a Python 3.11+ interpreter
already verified in this session. Otherwise try `py -3` on Windows or `python3`
elsewhere, then `python`, and check the version before the first helper call.
Choose locally; this needs no question to the user.

Use that executable wherever an example says `python` or `<verified-python>`,
including after `--run --`. Report a missing runtime only after finding no
suitable installed interpreter; the helper policy of the operation then says
whether a manual route exists.
