# Repository maintenance

- `scoville-code-anti-ai-slop/` is the independently installable package.
- `docs/` contains maintained documentation, provenance and evidence.
- `tests/` contains development tests or case definitions. Case definitions
  alone do not prove model behavior.
- Native planning remains under `docs/plans/` and `docs/decisions/`.
  Retained records preserve current ownership, decisions and evidence limits.
