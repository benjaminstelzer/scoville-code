# Version 1.0.18 veröffentlichen und installieren

## Goal

Der aktuelle Scoville-Code-Stand wird als unveränderlicher Patch-Release
`v1.0.18` auf `origin/main` und GitHub veröffentlicht. Danach bleiben remote
genau dieser SemVer-Tag und dieser GitHub Release erhalten. Die lokalen Codex-
und Claude-Installationen werden aus dem verifizierten Release-Tag ersetzt und
stimmen vollständig mit dem veröffentlichten Fünf-Dateien-Paket überein.

## Non-goals

- Keine Korrektur des offenen SkillOpt-Verhaltensbefunds in diesem Release.
- Keine Veröffentlichung des lokalen SkillOpt-Studio-Arbeitsbereichs.
- Keine Änderung oder Veröffentlichung anderer Scoville-Skills.
- Kein Verschieben, Überschreiben oder Neuerstellen eines bestehenden Tags.
- Keine Behauptung einer bestandenen Maintainability-Qualifikation.
